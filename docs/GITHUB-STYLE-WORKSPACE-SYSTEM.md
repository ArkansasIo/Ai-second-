# GitHub-Style Workspace System

AI Second Brain provides familiar project-management concepts inspired by modern Git hosting platforms, while remaining an independent interface and local-first system.

## Primary navigation

- Issues
- Code
- Pull Requests
- Agents
- Actions
- Projects
- Security
- Insights
- Discussions
- Releases
- Environments
- Packages
- Settings

## Issue system

Issues support title, description, labels, assignees, milestones, priority, status, project links, agent assignment, environment, dependencies, comments, attachments, and audit history.

Agents can triage, classify, summarize, propose fixes, and link issues to tasks. Changes that modify files or repositories remain subject to approval policy.

## Pull requests

Pull requests support source/target branches, changed files, diff review, automated checks, agent reviewers, comments, approvals, merge policy, and deployment/build results.

## Actions / automation

Actions are first-class workflows for build, test, lint, package, deploy, research, documentation, model tasks, and scheduled jobs. Workflows can execute inside a selected virtual environment.

## Projects

Project boards support table, board, roadmap, calendar, and dependency views. Cards may represent issues, pull requests, agent tasks, milestones, or arbitrary project work.

## Security

Security includes dependency findings, secrets policy, repository permissions, extension trust, environment isolation, command approvals, audit events, and optional security scanning adapters.

## Insights

Insights provide project health, task throughput, build/test status, agent utilization, resource usage, repository activity, release history, and workload trends.

## Releases

Releases contain version metadata, release notes, patch notes, artifacts, checksums, signing information, compatibility requirements, and rollback metadata.

## Environments

Each workshop can bind a repository to one or more virtual environments, such as C++, Python, Android, iOS, Unreal, Godot, Blender, or web. The environment owns toolchain configuration and resource policy.

## Quantity and capacity

AI Second Brain does not impose an artificial fixed number of projects, repositories, issues, agents, or tasks in the UI. Practical limits are controlled by local storage, CPU, RAM, GPU/VRAM, database capacity, configured concurrency, and platform resources.

## Project manager

The Project Manager agent uses milestones, roadmap items, dependencies, task estimates, owners, agent capacity, blockers, deadlines, and completion state to coordinate work. It can generate plans but cannot silently modify protected resources.
