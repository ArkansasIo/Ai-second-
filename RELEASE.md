# AI Second Brain 0.1.11

## Release state

- Version metadata is synchronized to `0.1.11`.
- **Brain LLM** remains the canonical main AI/LLM engine.
- Ollama remains the default local inference backend for Brain LLM.
- Agent execution has a canonical `BrainLLMAgentRuntime` bridge.
- Workspace lifecycle now supports rename, duplicate, move, delete, undo/redo, persistence, and validated JSON transfer contracts.
- Windows NSIS and portable EXE packaging remains automated with Electron Builder.
- Android debug and unsigned release APK packaging remains automated with Capacitor and Gradle.
- License remains pending final open-source/source-available selection.

## Build outputs

- Windows Electron Builder NSIS installer and portable EXE.
- Android debug APK.
- Android unsigned release APK.

Production Android and Windows signing credentials remain external to the repository.
