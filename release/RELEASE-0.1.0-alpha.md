# AI Second Brain v0.1.0-alpha

**Edition:** Professional  
**Developer:** ArkansasIo  
**Channel:** Alpha  
**Default AI:** Ollama local  
**Privacy:** Local-first

## Included

- React/Vite browser workspace
- Workshop environments
- Agent cluster UI
- Universal Blueprint graph foundation
- Blueprint-to-C++/Python/TypeScript generator
- Local API server
- Ollama model discovery and chat proxy
- Initial MySQL persistence schema
- GitHub Pages deployment workflow
- CI build/test pipeline
- Product branding and bootloader metadata

## GitHub Pages

The Pages site is the browser/test version. Native services such as MySQL, local filesystem execution, compilers, and Ollama remain local to the user's machine or an explicitly configured backend.

## Not yet production-complete

- Native desktop installers
- Android/iOS signed packages
- Full MySQL runtime adapter
- Streaming chat UI
- Full Blueprint editor
- Build/test worker sandbox
- Complete multi-agent scheduler
- Local STT/TTS runtime
- Release signing and update/rollback client

## Upgrade direction

The next alpha builds will progressively replace mock UI behavior with local API-backed projects, live Ollama conversations, persistent memory, executable environments, and agent-cluster scheduling.
